# VideApp

This is the VideApp-Var, as developed for the first module of Beethovens Werkstatt. Development took place roughly from 2015 to 2016, and is described in [DOI 10.5281/ZENODO.13289742](https://zenodo.org/doi/10.5281/zenodo.13289742). The original name of the tool was just VideApp, and "-var" was added later to indicate the first module, which dealt with variation. 

While this original VideApp inspired many later developments, it was never meant to be more than a prototype, and as such will not receive future updates and revisions, as most of the technology stack is seriously outdated. The version currently deployed at https://videapp-var.beethovens-werkstatt.de can be found in the */VideApp2016* folder.
